# Sporting and Technical Regulations 0.1

All entrants use the same AGP-01 specification, observation schema, base prompt, planning budget, physics and circuit state. Only livery, number, declared model identity and driving decisions differ.

Classification is ordered by completed laps and circuit progress. Contact and off-track running affect the simulated car. A result is not a valid benchmark if equipment, prompts, memory budgets, assists, protocol versions or environment constraints differ, or if a provider fails persistently.

The current offline exhibition is explicitly non-benchmark. Practice, qualifying, tyre allocation, pit lane, flags, neutralisation, penalties and championship points will be versioned before certified competition is enabled.
